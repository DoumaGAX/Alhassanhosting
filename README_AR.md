# Alhassan Hosting — النسخة الأولية

هذه نسخة أولية لواجهة استضافة ماينكرافت. حالياً إنشاء السيرفرات تجريبي داخل الواجهة فقط، وليس إنشاء سيرفر عام حقيقي.

## تشغيل الموقع
1. ثبّت Node.js إصدار LTS.
2. افتح مجلد `web` داخل المشروع في Terminal أو PowerShell. لا تشغّل `npm install` من المجلد الرئيسي؛ المشروع الذي يحتاج npm موجود داخل `web`.
3. نفّذ `npm install`
4. نفّذ `npm run dev`
5. افتح الرابط المحلي الذي يظهر لك.

## شنو موجود؟
- لوحة تحكم بنفسجية داكنة.
- قائمة السيرفرات.
- نافذة إنشاء سيرفر تجريبية.
- اختيار Paper / Purpur / Fabric / Vanilla.
- صفحات مبدئية للنسخ الاحتياطي والفوترة والإعدادات.

## قبل إطلاقه للناس
نحتاج تسجيل دخول آمن، قاعدة بيانات، خادم Linux دائم، عامل تشغيل يشغّل السيرفرات داخل حاويات معزولة، تحديد RAM/CPU/التخزين، مراقبة ونسخ احتياطي، حماية من الإساءة، وHTTPS. لا تشغّل ملفات المستخدمين أو أوامرهم بصلاحيات Administrator.


## تشغيل النسخة المحدثة محلياً
- استخدم Node.js إصدار 22.13 أو أحدث (الإصدار 24 يعمل أيضاً). لم نعد نستخدم `better-sqlite3` الأصلي؛ الـ API يستخدم `node:sqlite` المدمج في Node لتجنب بناء C++ على Windows.
- انسخ ملف `web/.env.local` الموجود عندك من النسخة القديمة إلى مجلد `web` في النسخة الجديدة حتى تبقى إعدادات Supabase محلية. لا ترفع هذا الملف إلى GitHub.
- من داخل `web` شغّل `npm install` ثم `npm run dev` لواجهة الموقع.
- في نافذة CMD ثانية من `web` شغّل `npm start` لتشغيل API المحلي. هذا الـ API لا يشغّل استضافة عامة وحده.
- بطاقة السيرفر تعرض المنافذ فور الإنشاء: Java TCP 25565 وBedrock UDP 19132. عنوان IP العام يظل غير مخصص إلى أن يتم ربط جهاز استضافة ومنافذ عامة حقيقية.


## ربط PocketMC
راجع الملف `POCKETMC_SETUP_AR.md` لإعداد اتصال آمن مع سيرفرات PocketMC الموجودة على الكمبيوتر. الربط الحالي يدعم عرض instances الموجودة والتحكم بتشغيلها وإيقافها وإعادة تشغيلها لحساب مالك الموقع فقط. إنشاء instance جديد من الموقع غير مدعوم عبر الـ API الموثقة حالياً.
